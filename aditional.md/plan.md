# План проекта VPd04_vk_weather

## Цель

Подготовить клиент OpenWeatherMap для погодного бота VK: текущая погода,
пятидневный прогноз, качество воздуха и геокодинг. Результаты должны содержать
русские тексты и стабильные английские ключи для интеграции с ботом.

## Очередь правок

- [проверено] Тексты помощи: прогноз, координаты и формулировка «ещё не выбран».
- [проверено] Второй город сравнения: динамический пример без первого города,
  проверка совпадения и повторный запрос.
- [проверено] Сравнение: тёплый город первым, данные двух городов до итога,
  итог с формулировками «теплее/ветренее/облачнее/влажнее».
- [проверено] Перенос погодного CLI в пакет `cli/` с разделением API и CLI.
- [проверено] Подписи прогноза и строка «Актуально на» в текущей погоде и
  сравнении.
- [проверено] Защита от нескольких экземпляров VK-бота: lock, автоостановка
  старых процессов и отчёт в `--check`.
- [проверено] Автоопределение координат в сообщении и запуск сценария
  «Геолокация» без нажатия кнопки.
