# План проекта VPd04_vk_weather

## Цель

Подготовить клиент OpenWeatherMap для погодного бота VK: текущая погода,
пятидневный прогноз, качество воздуха и геокодинг. Результаты должны содержать
русские тексты и стабильные английские ключи для интеграции с ботом.
